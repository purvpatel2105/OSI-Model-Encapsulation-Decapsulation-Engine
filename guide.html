How to Use the OSI Simulator

Learn how to operate the dual-PC network simulation, track live packet encapsulation, and explore network layers in real time.

🚀 Step 1: Launching a Simulation

To start observing how data travels across a network:

  1. Navigate to the Simulator page from the top menu.
  2. Locate the Source PC panel on the left side of your screen.
  3. Type any custom message or payload data into the input box (e.g., Hello Secure Network!).
  4. Click the Send 🚀 button to initiate transmission.

📦 Step 2: Understanding Encapsulation (L7 ➔ L1)

As soon as you click Send, the Source PC processes your message downwards from Layer 7 to Layer 1:

  • Layer 7 to 5 (Application, Presentation, Session): Formats the user data, handles encryption/TLS, and establishes session tokens. PDU: Data.
  • Layer 4 (Transport): Wraps data into Segments (TCP/UDP) and appends source/destination port numbers.
  • Layer 3 (Network): Encapsulates segments into Packets by adding Source & Destination IP addresses (e.g., 192.168.1.10 ➔ 192.168.1.50).
  • Layer 2 (Data Link): Wraps packets into Frames by adding MAC addresses and error checksum trailers.
  • Layer 1 (Physical): Converts the final frame into raw Bits (0s and 1s) ready for physical transmission.

⚡ Step 3: Transmission & Decapsulation (L1 ➔ L7)

Once bits cross the physical transmission medium hub:

  • The Destination PC receives the raw bits at Layer 1 and begins Decapsulation upwards from Layer 1 to Layer 7.
  • At each layer, headers and trailers are stripped and verified.
  • Finally, the original message is successfully delivered and rendered on the Destination PC output display!

🔍 Extra Features

  • Inspect Any Layer: Click on any layer card in the Source or Destination stacks at any time to open a detailed modal containing protocol specifications, ports, and working methods.
  • Pause & Reset: Use the control buttons in the central transmission hub to pause the simulation mid-way or reset it completely.
