Deep Dive into the 7 Layers of the OSI Model

The Open Systems Interconnection (OSI) model standardizes how data communicates across networks by breaking the process down into 7 logical layers—from user software down to physical cables.

Layer 7

Application Layer

What it does: Serves as the direct interface between user applications (like web browsers or mail clients) and the underlying network services. It identifies communication partners and resource availability.

Working Method: When you send a message, this layer formats your input data and prepares it for transmission. At the receiving end, it translates data into a readable format for the software.

Protocols: HTTP, HTTPS, FTP, DNS, SMTP PDU: Data
Layer 6

Presentation Layer

What it does: Acts as the "translator" of the network. It ensures that data sent from the application layer of one system can be easily understood by the application layer of another system.

Working Method: Handles data encryption/decryption (such as SSL/TLS security handshakes), data compression to speed up transfer, and syntax formatting (like JPEG, GIF, or ASCII translation).

Protocols: SSL/TLS, JPEG, MPEG, ASCII PDU: Data
Layer 5

Session Layer

What it does: Manages and maintains conversations (sessions) between local and remote applications. It handles opening, closing, and re-establishing connections.

Working Method: Sets up checkpoint synchronization so that if a connection drops, data is not lost entirely; it resumes from the last known checkpoint.

Protocols: NetBIOS, RPC, PPTP, SAP PDU: Data
Layer 4

Transport Layer

What it does: Ensures complete, reliable, or lightning-fast end-to-end data delivery between hosts. It breaks large messages down into manageable chunks and manages flow control.

Working Method: Uses TCP (connection-oriented, reliable delivery with acknowledgments) or UDP (connectionless, fast streaming without guarantees) and assigns port numbers.

Protocols: TCP, UDP, SCTP PDU: Segment (TCP) / Datagram (UDP)
Layer 3

Network Layer

What it does: Handles logical addressing (IP addresses) and determines the best physical routing path across multiple interconnected networks (routers).

Working Method: Encapsulates transport segments into Packets by attaching Source IP and Destination IP addresses so data knows exactly which device it needs to reach across the internet.

Protocols: IPv4, IPv6, ICMP, IPsec, OSPF PDU: Packet
Layer 2

Data Link Layer

What it does: Facilitates node-to-node data transfer between neighboring devices on the same local network (LAN) and detects errors from physical media.

Working Method: Wraps network packets into Frames by attaching Physical MAC addresses (Source MAC & Destination MAC) and adds a Frame Check Sequence (FCS) error-detection trailer.

Protocols: Ethernet, Wi-Fi (802.11), ARP, PPP PDU: Frame
Layer 1

Physical Layer

What it does: The absolute bottom foundation of networking. It manages the transmission of raw unstructured bits (0s and 1s) across physical hardware media.

Working Method: Converts frames into actual physical signals—such as electrical voltage levels over copper CAT6 cables, light pulses through fiber optics, or radio frequency waves over Wi-Fi.

Media: CAT6 Cables, Fiber Optics, Radio Waves PDU: Bits
